# Web Operations Runbook

1. Confirm deployment, tenant, affected route, browser, locale and user role.
2. Reproduce using a clean profile and supported viewport.
3. Check authentication, API, asset, cache and service-worker health.
4. Inspect CSP, CORS, cookies and browser-console errors without exposing secrets.
5. Validate English and Tamil content, keyboard navigation and screen-reader announcements.
6. Use an approved rollback or feature flag for customer-impacting regressions.
7. Record impact, mitigation, recovery evidence and follow-up actions.
8. Close only after sustained recovery across critical journeys.

Never copy credentials, tokens, payment data or sensitive child data into tickets or logs.
