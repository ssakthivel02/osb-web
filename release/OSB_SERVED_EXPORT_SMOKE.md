# OSB Training Academy — Served Export Runtime Smoke

Status: **AUTOMATED RUNTIME EVIDENCE — MANUAL UAT STILL REQUIRED**

## Purpose

This control validates the actual production static export generated by `npm run build` by serving the `out/` directory over local HTTP and requesting the learner-facing route surface.

## Scope

The smoke gate verifies:

- `/training-academy/`
- `/search/`
- all 19 canonical Training Academy track routes
- all physical learner-record routes present in the verified corpus
- a deliberately invalid route returns HTTP 404
- successful learner pages contain the expected `<main>` landmark and route-specific verification marker

## What this proves

It proves that the generated production export can be served over HTTP and that the canonical learner-route surface resolves from the built artifact instead of merely existing as source code or build metadata.

## What this does NOT prove

This is not a browser-interaction certification. It does not prove:

- search interaction after JavaScript hydration
- keyboard navigation or focus visibility
- WCAG conformance
- mobile/tablet responsive quality
- Chromium/Firefox/WebKit equivalence
- visual regressions
- screen-reader behavior
- funding/legal/safeguarding claim accuracy
- learner outcomes
- owner approval or production readiness

Those remain governed by `release/OSB_UAT_PROTOCOL.md`, `release/OSB_UAT_EVIDENCE.json` and `release/OSB_RELEASE_GATE.json`.

## Release decision

Passing this runtime smoke is necessary evidence, but production status remains `HOLD` until the exact final candidate satisfies all manual/external release gates.
