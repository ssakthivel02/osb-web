# Web Quality Evaluation

Required evidence:
- Critical learner, parent and administrator journeys pass end to end.
- Authorisation and tenant isolation are enforced by server responses, not UI state.
- English and Tamil routes have semantic parity.
- WCAG 2.2 AA checks cover keyboard, focus, contrast, zoom and screen readers.
- CSP, CSRF, secure-cookie, redirect and dependency controls are tested.
- LCP, INP and CLS budgets pass on representative mobile and desktop devices.
- Offline, stale-cache, service-worker and failed-API recovery paths are exercised.
- Privacy, analytics consent and sensitive-data minimisation are verified.

A green configuration validator is necessary but is not production evidence.
